# DSH Phone Control v0.1.2

首个公开源码版本：通过本地 stdio MCP，让支持图片和工具调用的 DSH 助手观察并操作一台授权安卓手机。

## 功能

- 手机连接检查、截图、界面节点和本地 OCR 文字目标。
- 文字点击、滑动、系统按键和启动应用。
- 局部放大、坐标尺、准星预览/确认及点击后反馈。
- 可选 scrcpy 4.1 剪贴板中文与 emoji 输入。
- 配置向导、只读环境检查、DSH 配置片段生成和给 AI 的安装说明。

## 安装与适用范围

需要自行安装 Node.js、Python、ADB，并在自己的手机上确认 USB 调试授权。中文/emoji 输入另需取得 scrcpy 4.1 服务端。安装步骤见仓库 README。

当前验证过 Windows、Node.js 24、Python 3.12、Android 10 USB 连接以及 DSH 0.1.1-rc.2 的 MCP 配置格式。独立入口通过 MCP SDK 和模拟手机检查，尚未在各种真实手机及完整 DSH 会话上普遍验收。

这是本地单用户 MCP，不是 QQ 桥接的自动补丁。QQ 接入仍需维护者保留主人身份、会话工具和群聊权限边界。模型可能选错目标；工具输入回执不代表任务成功。

## 验证

- Node 测试运行器报告 92 项通过，包含 MCP 挂载、参数约束、图片返回、串行调用和手机控制回归。
- 另有 12 项 Python 图像检查通过。
- 发布前核对源码清单、私人信息排除、许可文件及 ZIP 校验和。
- 本次发布验证没有发送手机输入或 QQ 消息。
